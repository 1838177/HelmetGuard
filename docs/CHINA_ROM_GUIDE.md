# HarmonyOS 4 与国内 Android ROM 可靠性

## 通用设置

1. 允许附近设备、精确定位、后台定位、短信、电话状态和通知权限。
2. 双卡设备明确选择求救 SIM。
3. 关闭 HelmetGuard 的电池优化/设为不受限制。
4. 开启自启动和后台活动，锁定最近任务。
5. 通过 Android 配套设备选择器关联头盔。
6. 保持“头盔持续监测”前台通知可见。

应用使用 `connectedDevice` 前台服务维护 GATT；事故定位阶段在权限允许时临时加入 `location` 类型。普通 GATT 在应用进程死亡后必然失效，因此没有任何 App 能在用户强行停止、撤销权限、关闭蓝牙或系统禁止自启动后承诺后台可用。

## 华为 HarmonyOS 4 / EMUI

- 设置 → 应用和服务 → 应用启动管理 → HelmetGuard。
- 关闭自动管理；同时允许自启动、关联启动、后台活动。
- 设置 → 电池 → 更多电池设置，允许后台高耗电/关闭电池优化。
- 最近任务中锁定 HelmetGuard。

本项目针对的是仍支持 Android APK 的 **HarmonyOS 4**，不包含 HarmonyOS NEXT/6 原生应用。

## 小米 / Redmi（MIUI、澎湃 OS）

- 设置 → 应用设置 → 授权管理 → 自启动管理。
- 应用详情 → 省电策略 → 无限制。
- 锁定最近任务。
- 不把流程建立在“后台弹出页面”权限上；紧急操作使用高优先级通知。

## OPPO / 一加 / realme

- 应用管理中允许自动启动和后台活动。
- 电池优化中设为不优化/允许后台高耗电。
- 锁定最近任务，系统升级后复查。

## vivo / iQOO

- 应用与权限 → 自启动 → 开启。
- 电池 → 后台耗电管理 → 允许后台高耗电。
- i管家白名单并锁定最近任务。

## 三星 One UI

- 电池和设备维护 → 后台使用限制。
- 加入“从不自动休眠的应用”。
- 应用电池设为“不受限制”。

## 为什么不使用无障碍自动点击

AccessibilityService 无法证明短信到达运营商，UI 文案和坐标会随品牌/版本变化，还可能误点并绕过安全确认。2.0 使用 `SmsManager` 的具体 subscription ID、每个分段唯一 `sentIntent`/`deliveryIntent`、静态 BroadcastReceiver 和 Room 持久化。应用只把 `RESULT_OK` 的发送回执记为“运营商接受”。

## 可验证与不可验证

可由应用验证：运行时权限、通知开关、蓝牙、定位总开关、电池优化豁免、联系人、SIM 选择和 BLE READY。

通常不可可靠验证：厂商自启动、关联启动、锁定最近任务、系统管家白名单。可靠性中心将其标记为人工确认，而不会伪造“已开启”。
